# 折桂 Zheg

> 让每一次秋招投递，都算数。

校园招聘表单填写助手 MVP。个人档案保存在本地，通过规则、识别记忆和可关闭的自动模型分析识别字段，检查预览后再填写，最终提交由你完成。

## 先体验演示

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5187 。内置虚构档案，点击右侧“识别表单”，查看档案来源和待填值，修改对应记录、取消勾选跳过，再点击“确认填写”。教育与实习的开始时间、两段教育经历、原生下拉和单选都可以体验。表单提交按钮不可用。

## 加载浏览器扩展

```sh
npm run build
```

1. Chrome 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。
3. 打开网申网页，点击工具栏中的折桂扩展图标，侧边栏会打开。
4. 在“本地档案”录入并保存，或导入 JSON；演示网页档案与扩展档案独立存储。
5. 点击“识别表单”，检查预览后确认填写。网页已有内容默认保留，逐字段选择后才覆盖。

首次可在档案页“载入虚构演示档案”并保存，在演示页面用真实扩展测试。扩展仅在用户点击工具栏图标时获得当前页面临时访问权；切换网页、刷新或权限不足时，在目标页面重新点击图标并重新识别。

## 自动智能识别与 API Key 测试

在“智能识别”中选择服务商和模型，默认 DeepSeek / `deepseek-chat`，服务地址自动填入。API Key 使用密码框填写；自定义兼容 Chat Completions 的服务可编辑 API 根地址和模型名称，本地无鉴权服务可留空密钥。

“测试 API Key”使用当前输入的配置发送最小聊天请求，不自动保存设置、不发送网页或档案信息。成功表示当前服务、模型和凭据能完成一次请求；401 / 403 / 429、网络、超时及无效回答会提示失败。测试可能产生少量费用；推理模型为得到最终回答可能使用更多 token。

点击“保存模型设置”，扩展会申请所选服务域名权限。自动智能识别默认开启，也可在本选项卡关闭，开关立即保存。**点击“识别表单”后，先使用规则和本地识别记忆，只有剩余待确认字段才自动调用模型。**打开网页、保存配置和编辑档案不会自动调用。没有密钥、访问权或模型调用失败时，可继续使用本地匹配和手动选择；更改设置后重新识别生效。

模型建议与记忆映射默认未勾选，需核对后选择，再点击“确认填写”；不会自动提交。确认填写成功的模型 / 手动映射按网站、板块、控件类型与选项保存在本地，下次复用以减少重复分析；已确认的手动纠正优先于通用规则。识别库不提供日常编辑界面，设置中可“清空识别记忆”，不影响档案。保留最近最多 500 条映射；不保存字段值、经历序号或密钥。未命名分组及含被过滤内容的标签不积累，未知但有名称的板块按名称隔离。

个人档案留在本地；自动分析发送过滤后的待确认标签、控件类型、分组及选项，不发送档案值、已有输入值、网页地址或 HTML，也不发送整个识别库。标签或选项仍可能包含页面个人信息，可关闭自动识别，并在设置页查看待发送 JSON。API Key 仅保存在扩展会话存储 / 演示页面内存，JSON 档案导出不含密钥或识别记忆。浏览器会话结束 / 演示刷新后需重新输入密钥。演示调用远程模型需要服务允许浏览器跨域访问。

升级保留现有档案（schemaVersion 1）和旧自定义模型配置，缺失自动开关时默认开启；回滚旧版本会忽略新增识别记忆，不需要删除档案。

## 首版支持及边界

- 支持文本、邮箱、手机号、文本域、原生日期 / 月份、单选组、原生单选下拉。
- 支持档案编辑、JSON 导入导出、分组上下文、多段已有经历的记录选择和填写结果反馈。
- 月份精度的档案遇到日精度控件会按当月 1 日填写，预览中提示检查。
- 暂不支持 iframe、跨页、自动新增经历、自定义下拉 / 日期控件、验证码、附件上传和自动提交。
- 当前没有针对具体招聘平台的适配；真实网站，尤其受框架控制的表单，需要进一步验证。
- 档案存于浏览器当前配置，无加密和云同步；导出的 JSON 含个人信息，请自行保管。

## 开发验证

```sh
npx playwright install chromium
make ci
make verify
```

可通过 `ZHEG_CHROME_PATH` 指定本机 Chromium 可执行文件。扩展集成测试需要 Playwright Chromium（品牌 Chrome 新版本限制命令行加载扩展）。测试覆盖规则上下文、重复经历、输入校验、已有值保护、模型 mock、异常降级和完整浏览器流程；不会调用真实模型服务。
