# 折桂 Zheg

> 让每一次秋招投递，都算数。

校园招聘表单填写助手 MVP。个人档案保存在本地，通过规则、识别记忆和可关闭的自动模型分析识别字段，检查预览后再填写，最终提交由你完成。

## 先体验演示

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5187 。内置虚构档案，点击右侧“识别表单”，查看档案来源和待填值，修改对应记录、取消勾选跳过，再点击“确认填写”。教育与实习的开始时间、两段教育经历、原生下拉和单选都可以体验。表单提交按钮不可用。

## 加载浏览器扩展

```sh
npm run build
```

1. Chrome 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。
3. 打开网申网页，点击工具栏中的折桂扩展图标，侧边栏会打开。
4. 在“本地档案”手动录入，或粘贴文本点击“载入个人信息”，检查并保存；演示网页档案与扩展档案独立存储。
5. 点击“识别表单”，检查预览后确认填写。网页已有内容默认保留，逐字段选择后才覆盖。

真实扩展初始档案为空，演示网页初次访问内置虚构档案。扩展仅在用户点击工具栏图标时获得当前页面临时访问权；切换网页、刷新或权限不足时，在目标页面重新点击图标并重新识别。

## 自动智能识别与 API Key 测试

在“智能识别”中选择服务商和模型，默认 DeepSeek / `deepseek-chat`，服务地址自动填入。API Key 使用密码框填写；自定义兼容 Chat Completions 的服务可编辑 API 根地址和模型名称，本地无鉴权服务可留空密钥。

“测试 API Key”使用当前输入的配置发送最小聊天请求，不自动保存设置、不发送网页或档案信息。成功表示当前服务、模型和凭据能完成一次请求；401 / 403 / 429、网络、超时及无效回答会提示失败。测试可能产生少量费用；推理模型为得到最终回答可能使用更多 token。

点击“保存模型设置”，扩展会申请所选服务域名权限。自动智能识别默认开启，也可在本选项卡关闭，开关立即保存。**点击“识别表单”后，先使用规则和本地识别记忆，只有剩余待确认字段才自动调用模型。**打开网页、保存配置和编辑档案不会自动调用。没有密钥、访问权或模型调用失败时，可继续使用本地匹配和手动选择；更改设置后重新识别生效。

模型建议与记忆映射默认未勾选，需核对后选择，再点击“确认填写”；不会自动提交。确认填写成功的模型 / 手动映射按网站、板块、控件类型与选项保存在本地，下次复用以减少重复分析；已确认的手动纠正优先于通用规则。识别库不提供日常编辑界面，设置中可“清空识别记忆”，不影响档案。保留最近最多 500 条映射；不保存字段值、经历序号或密钥。未命名分组及含被过滤内容的标签不积累，未知但有名称的板块按名称隔离。

网页字段识别时，个人档案值留在本地；自动分析发送过滤后的待确认标签、控件类型、分组及选项，不发送档案值、已有输入值、网页地址或 HTML，也不发送整个识别库。标签或选项仍可能包含页面个人信息，可关闭自动识别，并在设置页查看待发送 JSON。演示调用远程模型需要服务允许浏览器跨域访问。

**API Key 输入后点击“保存模型设置”，以后重新打开页面、侧边栏或重启浏览器都会恢复。**扩展保存在本机 `chrome.storage.local`，演示保存在当前网站的 `localStorage`，使用独立的 `modelCredential`，不进入档案、识别记忆或模型请求正文。扩展存储仅允许可信扩展上下文访问；网页和注入脚本无法读取。存储不加密、不云同步；演示不同地址 / 端口、不同浏览器配置与扩展之间不共享密钥。

“清除已保存 API Key”会清除密钥，保留档案、模型配置和识别记忆。更换服务商或地址时输入框会清空，请输入该服务的密钥并保存；已保存凭据绑定服务地址。测试按钮只测试草稿，不保存或替换密钥。保存失败会明确提示，请检查浏览器是否允许本机存储并重试。

升级后仍存活的旧扩展会话密钥自动迁移；已经丢失的密钥需要最后输入并保存一次。卸载扩展、清除网站数据、隐私窗口关闭或更换浏览器配置后需重新保存。正式扩展更新请保留同一扩展 ID 和浏览器配置；开发模式应在同一路径重新构建并点击扩展“重新加载”，避免删除再安装。回滚到旧代码前可先清除已保存密钥，旧版恢复会话 / 页面内存行为。

## 粘贴载入与自定义档案

“本地档案”顶部可粘贴简历、经历描述、列表、表格或 JSON 等**文本**，点击“载入个人信息”用已保存的模型配置整理。这个操作与网页识别不同：**会把粘贴原文和已有板块 / 小标题发送给模型服务商**，不发送现有档案值、网页信息或识别记忆。仅点击后发起请求，最多 20000 字；不处理文件、图片或 OCR。关闭自动网页识别后，仍可主动使用文本载入。

模型识别后自动分类到基本信息、教育、实习或新的命名板块，结果先进入编辑草稿，核对后点击“保存档案”才持久化。保留已有非空个人信息，标准字段已删除时不自动恢复；冲突会提示。重复经历仅在身份信息及已有内容一致时合并，不确定时增加记录，请自行检查。模型可能误判或遗漏，请核对原文。调用失败 / 未配置 / 权限拒绝 / 无效结果不改变当前草稿或已保存档案。粘贴原文只保留在当前页面内存，刷新即清空。

粘贴内容不必手动统一日期：识别结果中的 `2025-7-28`、`2025.07`、`2025/07/28`、`2025年7月28日` 等明确日期会按档案月份精度保存为 `2025-07`（不保留日精度）。只有年份、至今、日期区间或无效日历日期会保留为文本供核对，不因这些日期写法拒绝整份资料；若对应标准 / 已有日期字段，则另存“标题（原文）”，原月份输入框保留。日期空白不会补造。原有非空姓名等内容仍不会自动覆盖，请在编辑区检查并修改，最后保存。

- 每条记录下方展开“添加信息”，输入小标题（如“是否有实习证明”）和内容（如“是”），再点击“添加信息”。
- 标准或自定义字段右上角的“×”同时删除小标题及内容；修改后保存生效。所有字段添加后显示固定标题，只能编辑内容；需要换名时删除后重新添加。
- 底部输入新板块名称（如“家庭信息”），点击“新增板块”；新板块可添加 / 删除记录或删除整个板块。基本信息保留一条记录，教育 / 实习保留板块但可删除记录及字段。
- 新增信息也可用于后续网页规则匹配、模型映射、手动来源选择与识别记忆，保持预览确认填写。

上限：20 个自定义板块、每板块 20 条记录、每记录 50 个自定义字段、全档案 500 个可见字段 / 1 MB；标题最多 80 字，内容最多 5000 字，日期使用 YYYY-MM。

档案升级为 schemaVersion 2，旧版本 1 自动兼容读取，首次保存新版前把原版本 1 档案保留到本机 `profileV1Backup`，不重复覆盖。旧识别库中不存在的路径被忽略，保存时清理。回滚旧代码前需保留当前版本 2 存储并恢复旧快照；快照不含升级后的新信息且可能包含后来删除的信息，不能将旧版直接运行视为无损回滚。无旧快照的新安装可投影标准字段回滚，详见[设计说明的迁移与回滚](docs/MVP软件设计说明书.md#升级与回滚)。

## 首版支持及边界

- 支持文本、邮箱、手机号、文本域、原生日期 / 月份、单选组、原生单选下拉。
- 支持粘贴文本模型整理、档案板块 / 字段增删、分组上下文、多段已有经历的记录选择和填写结果反馈。
- 月份精度的档案遇到日精度控件会按当月 1 日填写，预览中提示检查。
- 暂不支持 iframe、跨页、自动新增经历、自定义下拉 / 日期控件、验证码、附件上传和自动提交。
- 当前没有针对具体招聘平台的适配；真实网站，尤其受框架控制的表单，需要进一步验证。
- 档案存于浏览器当前配置，无加密和云同步；不再提供 JSON 导入 / 导出或演示档案载入按钮。卸载扩展或清除浏览器数据会丢失本机信息。
