# REQ-20261009-05 API Key 本机持久保存

用户目标：保存一次模型设置后，重新打开演示页面、扩展侧边栏及重启浏览器均无需重新输入 API Key。
范围：独立凭据存储、旧扩展会话密钥迁移、显式清除、存储失败提示与隐私回归。
不包含：云同步、加密保险库、多服务商密钥管理、真实供应商联调或改变模型调用时机。

验收标准（实现前定义）：
- A1：保存后刷新 / 关闭再打开演示页面恢复密码框与配置；真实 MV3 扩展关闭并重新启动同一浏览器配置后恢复，使用恢复的凭据完成 mock 请求。
- A2：测试 API Key 只使用草稿，不保存；替换密钥保存后恢复新值；清除已保存密钥后刷新 / 浏览器重启仍为空，档案、配置和识别记忆不受影响。
- A3：凭据只存于独立 modelCredential，不进入档案、配置、识别记忆、模型正文或错误提示；扩展 local 存储限制为可信扩展上下文。变更服务商 / 地址时清空表单中的旧密钥，不把已保存凭据自动带到其他地址。
- A4：仅在持久凭据不存在时迁移旧 session.modelKey；空凭据标记 / 非法持久数据不回退到旧密钥。读写失败有不含密钥的提示，不假报保存 / 清除成功，保留本地手动路径。

链路影响：
- 产品 / 技术设计：docs/MVP软件设计说明书.md 更新存储、迁移、清除、访问边界和失败行为。
- 代码：src/storage.js 独立凭据读写与迁移，src/app.js 恢复 / 保存 / 清除及错误提示。
- 测试：tests/storage.test.js 存储与拒绝边界；tests/e2e/workflow.spec.js 演示恢复 / 清除 / 草稿 / 错误回归；tests/e2e/extension.spec.js 真实扩展浏览器重启与权限隔离。
- 配置：不涉及新增环境变量、依赖或权限；现有 storage 权限足够，Makefile / CI 命令不变。
- 运行：README.md 更新保存、升级和本机数据边界，本文记录验证和交付。
- 后端 / 数据库：不涉及，本项目为浏览器扩展，无业务后端和数据库。
