用户目标：开发可体验的网申识别与预览填写 MVP。

范围：Chrome / Edge MV3 侧边栏扩展、本地档案编辑及 JSON 导入导出、分组上下文规则映射、可选模型消歧、可编辑预览、确认填写、演示表单。
不包含：自动提交、跨页、iframe、自动新增经历、简历文件解析、复杂第三方控件、真实招聘平台全面适配。

验收标准（实现前定义）：
- A1：档案保存刷新可恢复；非法 JSON / 数据结构拒绝，不覆盖原档案。
- A2：相同“开始时间”在教育、实习中映射到不同路径；重复分组可选择不同记录。
- A3：识别不写入表单；确认后仅填写选中的字段；保留已有值，覆盖需手动启用。
- A4：模型请求不包含档案值、已有输入值、页面 URL、HTML；校验字段 ID、路径、类型、重复结果；异常降级到手动处理。
- A5：页面变动或控件不支持时报告失败；不自动提交。
- A6：演示完整流程通过浏览器测试；扩展打包可加载，验证扫描与填写通信。
