# REQ-20261010-03 修复空值匹配复核及分板块来源选择

用户目标：档案有值时预览正确取值；规则匹配但没有可填值的字段也进入模型复核；手动来源按板块选择，避免全档案长列表。
范围：路径与记录索引一致性、缺失记录明确显示、模型复核条件 / 来源索引、两级来源选择、记录切换及已保存档案提示。
不包含：猜测缺失日期、自动复用首条记录填多段经历、向模型发送档案值、自动勾选模型建议、修改网页已有值保护或自动保存。

验收标准：
- A1：基本信息路径恒用记录 0；经历按网页分组顺序分配，不存在的记录明确显示“无对应档案记录”，来源列表不伪选第一项；用户改为有效记录后预览 / 勾选 / 填写一致。
- A2：无路径、记录不存在、值为空或无法转换为网页选项的字段进入规则 / 记忆之后的模型复核；本地有可用值不重复发送。模型只看标签 / schema，不看档案值；模型建议不勾选，不确定 null 保留原匹配，失败保留本地路径；缺失值仍提示补档案，不猜日期。
- A3：来源先选兼容板块，再选该板块字段，字段按记录分组；模型和规则来源自动定位板块。切换板块清空旧路径与勾选，选择有效字段后预览取正确记录；删除字段 / 类型不兼容不出现。记录切换不改变跨板块手动来源。
- A4：保存前档案草稿不用于填写，界面说明使用已保存档案；测试正常、缺失记录、关闭模型 / 模型失败、手动选择、已有值保护、跨记录及狭窄屏幕。
