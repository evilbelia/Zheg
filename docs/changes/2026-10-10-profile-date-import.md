# REQ-20261010-01 粘贴识别日期兼容修复

用户目标：粘贴含完整日期或不同日期写法的个人信息后，识别结果可以进入编辑区，不因一个非 YYYY-MM 日期导致全部信息未载入。
范围：模型提取日期规范化、不能确定年月时按原文文本保留、标准 / 已有日期字段安全合并、载入提示与日期别名。
不包含：自动覆盖已有非空档案、自动保存、改为日精度存储、自动推断缺失日期、真实个人资料或模型密钥联调。

验收标准（实现前定义）：
- A1：模型返回 YYYY-M、YYYY.MM、YYYY/MM、中文年月及合法完整日期时按月规范化，text 类型的标准日期也可识别；其他有效个人字段同时载入。
- A2：年份、日期区间、至今或非法日期不猜测月份，不被截断伪装成合法日期；保留为文本。标准 / 已有 date 类型字段的原文另存“标题（原文）”，不得写入非法 month 值；删除过的标准日期不恢复。
- A3：模型结果进入草稿，可保存并在刷新后恢复；载入前不变更持久档案；已有非空值、删除状态保留，重复载入不新增相同记录或原文字段。
- A4：非法 JSON、字段类型 / 容量 / 重复字段等结构错误仍整批拒绝；拒绝时当前草稿与保存数据不变。请求仍仅发送主动粘贴文本及 outline，20 秒超时、权限与鉴权策略不变，不额外调用模型。
