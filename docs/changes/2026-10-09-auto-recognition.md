# REQ-20261009-02 自动智能识别与本地识别记忆

用户目标：点击识别即可完成规则与模型消歧，复用确认过的字段映射；简化 DeepSeek 配置并可测试 API Key。

范围：默认开启自动智能识别、设置页关闭开关、按网站与板块保存本地识别记忆、DeepSeek / 自定义服务配置、连接测试。
不包含：自动提交、打开网页即调用、模型训练、动态新增档案板块、云同步、保存个人值至识别库、真实供应商联调。

验收标准（实现前定义）：
- A1：默认 DeepSeek / deepseek-chat；保存配置后点击识别，规则先处理，只对剩余字段自动调用一次模型；关闭后不调用；全匹配不调用。
- A2：识别不填写，模型建议默认未勾选；缺密钥、权限拒绝、HTTP / 网络 / 超时 / 非法输出均可继续手动填写。
- A3：模型建议不直接入库；仅成功确认填写的模型或手动映射入库，下次同网站、同板块、同控件及选项匹配可复用；不同网站、板块、类型和选项不串用，非法记忆拒绝，可清空。
- A4：服务商和模型使用下拉框，DeepSeek 默认地址自动填入，自定义地址与模型可编辑；API Key 为密码框，仅会话保存且不进入档案导出。
- A5：测试按钮使用当前输入配置发起最小 Chat Completions 请求，无档案或网页信息；验证有效回答；401、403、429、网络、超时及无效响应明确提示；不自动保存配置、不泄露服务响应或密钥。
- A6：真实 MV3 自动识别流程验证权限与存储，记忆刷新恢复；完整质量门通过。
