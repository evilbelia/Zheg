# REQ-20261009-03 文本载入与可扩展本地档案

用户目标：移除本地档案中的 JSON 导入 / 导出与演示档案载入，以粘贴任意格式文本并由模型归类添加；可新增大板块及记录中的小标题 / 内容，并用 x 删除字段。

范围：纯文本粘贴模型载入、编辑草稿、标准与自定义字段增删、自定义板块 / 多记录、动态档案映射与识别记忆、旧档案兼容升级。
不包含：附件 / OCR、模型训练、自动提交、云同步、自动持久化模型结果、恢复被删字段、真实模型联调。

验收标准（实现前定义）：
- A1：旧入口消失；档案顶部有文本框和“载入个人信息”；支持杂乱文本、列表 / JSON 文本，点击才发送原文，不发送旧档案值 / 网页；明确提示原文会发送；空白 / 超长文本不调用。
- A2：模型输出校验后归类到标准 / 新板块并进入草稿；个人非空值不覆盖，已删除字段不恢复；重复记录保守合并 / 去重，冲突保留原值并提示；失败 / 未配置 / 无权限 / 非法输出保持原草稿与已保存数据；保存后刷新恢复。
- A3：各板块每条记录可以“添加信息”，输入小标题与内容；标准 / 自定义字段右上角 x 删除，两者同时移除且保存后不再映射；新增家庭信息等同级板块，可增删记录 / 自定义板块；空标题、重复标题、无效日期、容量超限拒绝。
- A4：新增字段 / 板块出现在填写来源中，按上下文处理重复记录、规则 / 模型支持动态路径；识别记忆仅接受当前存在的路径，字段删除后旧映射失效；未知路径、类型不兼容和重复 ID 拒绝。
- A5：版本 1 数据读取兼容升级到版本 2，保存前保留原数据；提供可重复迁移与回滚说明，不丢失标准值；纯文本原文只在当前页面内存，密钥不入档案，模型输出不执行 HTML / 指令。
- A6：单元、浏览器与打包扩展完整流程通过，make ci 与 make verify 全通过。
