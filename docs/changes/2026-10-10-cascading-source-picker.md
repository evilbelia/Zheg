# REQ-20261010-04 单个级联来源选择器

需求标识 / 用户目标：REQ-20261010-04。填写预览每条信息只显示一个来源选择框，减少两个常驻下拉的重复占位，按板块 → 信息快速选择。

范围 / 不包含：演示与 MV3 共用界面；保留分组级对应记录选择。模型调用、档案保存、协议、权限、存储结构均不改变。

验收标准：
1. 每行收起时只有一个来源按钮，已匹配显示完整来源，缺失记录明确提示。
2. 打开先显示兼容板块；选择板块后显示该板块字段，按记录分组；支持自定义板块，排除删除及类型不兼容字段。
3. 仅选择有效字段才更新映射、待填值和勾选；浏览板块、返回、Esc、点击外部、Tab 离开均不改变已有映射。同时只打开一个菜单。
4. 支持 Enter / 空格、上下方向键、Home / End、左右层级导航和 Esc，关闭后合理恢复焦点；窄屏无横向溢出，长列表可滚动。
5. 保留规则 → 记忆 → 模型复核、缺失记录 / 空值提示、跨板块来源和确认填写；操作选择器不调用模型。
