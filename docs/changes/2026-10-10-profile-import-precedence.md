# REQ-20261010-02 粘贴信息优先覆盖同一词条

用户目标：同一词条以本次粘贴识别出的新值为准，解决已有 / 示例值挡住新值；模型先分类并复用同义标题，程序确定覆盖行为和记录边界。
范围：同名 / 标准别名字段覆盖、模型复用现有小标题、经历身份匹配、本次载入记录优先排序、更新计数与草稿保存说明。
不包含：发送现有档案值给模型、增加第二次模型请求、自动覆盖网页已有值、自动保存、按序号猜经历、删除未提到的记录或恢复用户删除的标准字段。

验收标准（实现前定义）：
- A1：姓名 / 手机等标准别名、自定义字段在同一记录中以新非空值覆盖；未提供的字段保持；相同值重复载入新增 / 更新均为 0；显示新增与更新数量。模型提示明确复用同义小标题，不混淆主邮箱 / 备用邮箱等不同词条。
- A2：教育按学校、实习按公司识别，双方都有开始日期且不同则分开；相同身份的职位 / 描述 / 结束日期可更新。自定义记录优先姓名 / 项目名等明确身份，关系只有唯一匹配且无姓名冲突时使用；不确定时新增，不能按记录位置覆盖。
- A3：本次载入记录按粘贴顺序排在所在板块前面，其他记录保留，包括示例记录；不同身份不因字段名称相同被合并。保存时清除旧扫描状态，重新识别默认选用新记录。
- A4：仅更新编辑草稿，保存前本机档案和网页保持不变；保存刷新后恢复。已删除标准字段不恢复，日期兼容和原文保留机制不变；模型同义字段冲突、结构非法、权限 / 网络失败或容量超限时整批拒绝并保留原草稿和存储。
- A5：模型只看到主动粘贴文本与已有标题 outline，无现有值、密钥、网页或识别记忆；同义判断与提取在同一次请求内，不能执行模型给出的路径 / ID。
